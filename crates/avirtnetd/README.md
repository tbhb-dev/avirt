# avirtnetd

The guest networking daemon provides the client end of the workload's HTTP/2 connection to its mediator. It also provides the TUN, transparent TCP listeners, optional forward proxy, reverse proxy, DNS stub resolver, and guest control API. It runs in the sandbox container.
